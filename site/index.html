How it works

No new sign-in and no account juggling. The extension adds Google's own authuser= parameter to the link before the page loads, so the service opens in the account you picked.

  1. Add your accounts

    Type the email addresses you're already signed in to in this browser.

  2. Pick a default per service

    Gmail → work, YouTube → personal, Drive → side project. Or leave a service alone.

  3. Just click links

    Every link opens in the right account. Need another one? Reopen the page as any account from the toolbar.

Small, quiet, private

A tool you install and forget. It reads Google and YouTube addresses only to decide where to send them.

  • Your account list and settings stay in your browser.
  • No passwords, cookies or browsing history are stored. Google still handles sign-in.
  • Access is limited to google.com and youtube.com pages.
  • Only an anonymous daily usage count is sent to the developer: no emails, no URLs, no ID. In Firefox you can turn it off in the add-on's permissions.
  • No ads, no remote code. Read the privacy policy.

Install in Firefox

Click the button, then confirm “Add” in the Firefox prompt. If Firefox asks whether to allow this site to install add-ons, choose “Continue to installation”.
